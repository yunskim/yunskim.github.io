Exponential Function

exponential function는 같은 비율로 증가하고 감소하는 함수이다.

2026-XX-XX

math statistics

\(f(x + y) = f(x) \cdot f(y) \)

그림으로 이해하기

\(y\) 대신 \(dx\)

\( f(x + y) = f(x) \cdot f(y) \)을 조금만 변형해보자.

x의 증가분 \(dx\)를 \(y\)자리에 넣으면 맥락없는 \( y \)를 넣은 때보다 패턴이 선명하게 보인다. \[ f(x + dx) = f(x) \cdot f(dx). \] 이게 무슨 뜻일까? 좌변 \( y \)자리에 \( dx \)가 들어간, \(x\)보다 \(dx\)만큼 증가한 지점의 함수값 \(f(x + dx)\)가 \( f(x) \)와 \( f(dx) \)의 multiplication이라는 것이 무슨 뜻인가?

일단 그려보기

무언가 패턴이 있을 것 같은데 답이 입 안에서 맴돌 뿐 입 밖으로 나오지 않는다면 일단 그림 논의를 단순화하기 위해 \(c = 1 \)로 정한다. 을 그려보자. \(x\)와 \(dx\)를 바꿔가며 패턴을 찾아보자.

\(f(dx)\)는 비율 \(dx\)을 입력을 받아 늘어난 값을 구하는 함수

충분히 작은 \(dx\)에 대해 \(f(x + dx)\)는 \(f(x) \cdot (1 + dx)\)에 근사하는 것을 발견했나?

\(f(x)\)가 10% 증가한 값을 \( f(x) \cdot (1 + 0.1) \)로 구한다. 마찬가지로 \(f(x)\)가 \(dx\)증가했다면 그 값은 \(f(x) \cdot (1 + dx) \)이다. \(f(dx) \approx (1 + dx) \)는 마치 증감율 \(dx\)을 받아 실제 증감을 계산하는 함수처럼 보인다.

이 방향으로 조금 더 사고를 확장해보자. \(f(dx + dx + dx)\)는 단계 \(x\)를 \((dx + dx)\), \(y\)를 \(dx\) 를 나눠 규칙을 적용할 수 있다. \[f((dx + dx) + dx) = f(dx + dx) \cdot f(dx) = f(dx) \cdot f(dx) \cdot f(dx) \approx f(dx)^3. \] 요약하자면 입력의 sum은 출력의 product로 표현된다.

한 번 더 일반화해 \(x\)가 \(dx\)가 \(n\) 개여 더해진 결과라고 보면:
\[f(dx + dx + dx + \ldots) = f(dx) \cdot f(dx) \cdot f(dx) \cdot \ldots \approx (1 + dx) ^ n = \left(1 + \frac{x}{n}\right)^n. \] 이 표현을 합과 곱 기호로 적으면:
\[f\left(\sum_{i=1}^{n} dx\right) = \prod_{i=1}^{n} f(dx) \approx (1 + dx)^{n} = \left(1 + \frac{x}{n}\right)^n.\] 여기서 \(x = n \cdot dx \)이다.
\(\sum\)은 addition을 n번 반복, \(\prod\)은 multiplication을 n번 반복하는 표기.

\(x\)를 마치 아주 작은 비율 \(dx\)의 합처럼 볼 수 있고 함수값 \(f(x)\)는 비율 \(dx\)를 모두 적용한 값으로 해석이 가능하다. 입력은 비율들의 addition, 출력은 비율이 적용된 multiplication로 이해할 수 있다. \(f(x + y) = f(x) \cdot f(y) \)라는 최소한의 가정에서 시작해 함수의 특성 파악까지 생각을 확장한 결과이다.

derivative

\(f(x + y) = f(x) \cdot f(y)\)에서 derivative 유도하기

\(f(dx) \approx (1 + dx)\)을 가정한 것이 마음에 들지 않는다면 이번에는 formal하게 derivative를 구해보자. 정의대로 쓰면:
\[ \begin{align} f'(x) &= \displaystyle \lim_{ h \to 0 } \frac{f(x + h) - f(x)}{h} \\\\ &= \lim_{ h \to 0 } \frac{f(x)f(h) - f(x)}{h} \\\\ &= \lim_{ h \to 0 } f(x) \cdot \frac{f(h) - 1}{h} \\\\ &= f(x) \cdot \lim_{ h \to 0 } \frac{f(h) - 1}{h}. \end{align} \]

여기까지 유도하고 중간 결과에 대해 이야기 해보자. 아직 limit process가 끝나지는 않았지만 많은 정보를 얻을 수 있다.

  • \(f'(x)\)는 \(f(x)\)값에 비례한다.
  • \(f'(x)\)는 \(x\)값에 상관없이 \(\displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h}\)라는 동일한 factor에 비례한다. 다른 말로 옮겨보면 함수의 모든 값을 \(\displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h}\)가 결정한다.

\(f(0)\) 구하기

\(f(x + y) = f(x) \cdot f(y) \)일 때 \(x\), \(y\)에 둘 다 \(0\)를 넣어보자. \[\begin{align} f(0) &= f(0 + 0) \\\\ &= f(0) \cdot f(0) \\\\ &= f(0)^2. \end{align}\] \(f(0) = f(0)^2\)라면 \(f(0) = 0\)이거나 \(f(0) = 1\)이다.

\(f(0) = 0\)이라면 \(f(x) = f(0 + x) = f(0) \cdot f(x) = 0 \)이라는 결과가 나와 모든 \(f(x)\)가 \(0\)이 되니 큰 쓸모가 없어진다. \(f(x + y) = f(x) \cdot f(y)\)조건은 충족하지만 바람직한 답은 아니다.

따라서 남은 \(f(0) = 1 \)을 선택할 수밖에 없다. 이 값을 limit process의 남은 항 \(\displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h}\)에 대입하면:
\[\begin{align} \displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h} &= \displaystyle \lim_{ h \to 0 } \frac{f(h) - f(0)}{h - 0} \\\\ &= f'(0). \end{align} \]

최종 derivative

두 개의 factor를 다시 정리하면:
\[ f'(x) = f(x) \cdot f'(0). \] \(f'(0)\)값에 따라 \(f(x)\)의 모든 값 \(f(0) = 1\)은 이미 알고있다. 이 정해진다. \(f'(0)\)을 함수를 결정하는 일종의 하이퍼 파라미터처럼 다루기로 하자.

앞으로 \(f'(0) = c\)로 표기하기로 한다. 보통 상수를 함수 앞에 쓴다.

마지막으로 정리하면:
\[ f'(x) = c \cdot f(x). \]

\(f(x)\)는 \(f(x)\) 자신에 비례해 증가하고 감소하며 상수 \(c\)로 함수의 모든 값을 결정할 수 있다는 결론이다. 특히 \(c = 1\)인 경우를 \(\displaystyle e^x\)로 표기하며 exponential function이라고 칭한다.

\(\displaystyle e^x\)는 결국 derivative가 자기 자신인 함수이다. 값이 얼마가 되었든 자신의 값에 비례해 증가 \(x\)가 음수라면 감소 하는 함수이다.

\(f'(x) = c \cdot f(x) \)의 의미

같은 비율로 증가하려면 현재의 함수값을 알아야 한다.

\(f’(x)\)는 x지점 근처의 x의 증감에 대해 \(f(x)\)가 얼마나 변화하는지 변화량을 알려주는 함수이다. \(x\)의 충분히 작은 증감 \(dx\)에 대해 \(f(x)\)의 값이 얼마나 바뀌는지 알려준다.

\(f’(x)\)는 증감하는 비율이 아니라 증감하는 값을 가리킨다. 따라서 값에 상관없이 같은 비율로 증감하는 모델을 만들려고 하면 지금 값을 알아야 할 필요가 있다.

예를 들어보자. 당신은 은행에 예금 계좌를 열었다. 이자율이 10%라고 하다. 1만원을 예치했다면 이자액 다시 말해 원금에 더한 증가액은 1만원의 10%인 1천원이다. 이제 여유가 되어 100만원을 예치한다고 하자. 이 경우 이자액은 100만원의 10%인 10만원이다. 같은 비율로 증가하지만 증가하는 값을 구하려면 현재 예치한 금액을 알아야 한다.

큰 값은 큰 값에 비례해, 작은 값은 작은 값에 비례해 증가하고 감소하는 모델의 derivative에 f(x)가 들어가는 이유이다.

월급 인상율: 값이 크면 증가분도 크다

같은 비율로 증가하는 모델의 의미를 예를 들어 생각해보자.

같은 비율로 오른다는 말은 같은 금액이 오른다는 뜻이 아니다. 이미 큰 값을 가진 경우 같은 비율에서도 더 큰 절대 증가액을 얻는다. 비율이 동일할 뿐 실제 증감액은 초기값에 따라 큰 차이가 난다.

카페인 대사: 값이 작으면 감소도 조금만

카페인은 몸 안에서 일정한 양이 빠지는 것이 아니라 일정한 비율 자료:
EFSA, caffeine and increased alertness, CDC/NIOSH, Caffeine & Long Work Hours 로 줄어든다. 반감기를 5시간으로 단순화하면 150mg의 카페인은 5시간 뒤 75mg, 10시간 뒤 37.5mg이 된다.

체내 카페인이 완전히 사라지기까지 오랜 시간이 걸린다. 같은 비율로 줄어든다면 시간이 지날수록 카페인이 분해되는 양은 줄어든다. 분해되는 비율은 일정하다.

일반화

\( c \)가 \(1\)이 아닐 때

exponential function의 일반해는 \(f(x)=e^{cx}\)이다. \(c\)값에 따라 다른 함수가 정의된다.

\(2^x\)도 exponential function

\(2^{x + y} = 2^x \cdot 2^y \)을 만족하는 만큼 \(2^x\)도 \(e^{c \cdot x}\) 형태로 바꿀 수 있다. 그러면 이 경우 \(c\)를 얼마로 잡아야 할까?

임의의 \(x\)에 대해 \(e^{c \cdot x} = 2^x\)로 표현할 수 있고, 계산을 편하게 하기 위해 \(x = 1\)을 넣어보자. \(e^c = 2\)라는 관계가 나오고 양변에 \(log\)를 잡으면 \(c = \log2\)라는 답이 나온다.

\(10^x\)도 exponential function

\(10^{x + y} = 10^x \cdot 10^y \)이 성립한다. 동일한 방법으로 \(c = \log10\)을 구할 수 있다.

\(e\)는 실수

\(2^x\)의 2, \(10^x\)의 10과 마찬가지로 \(e^x\)의 \(e\)또한 특별할 것 없는 실수이다. \(f(x)=e^{c \cdot x}\)에서 \(c = 1\)을 만족시키는 실수를 기호로 표현할 뿐, 2보다 덜 할 것도 없고 10보다 못할 것도 없는 실수비율 c에 대응하는 실수라는 점에 대해서는. 실제로 여러가지 성질이 있지만 그걸 아는 사람이 이 글을 읽고 있을 리가 없잖아요.에 불과하다.

\(e\)는 2.7187...으로 무리수이다.

score function

지수함수 \(f(x)=e^{cx}\)의 특별한 점은 미분해도 자기 자신의 상수배가 된다는 것이다. 즉 \(f'(x)=c e^{cx}\)이고, 어떤 지점 \(x=a\)에서의 기울기도 \(c e^{ca}\)이다. 그래서 수준 \(f(x)\)는 지점마다 달라지지만 상대 변화율 \(\frac{f'(x)}{f(x)}\)는 항상 \(c\)로 일정하다.

함수의 상대변화율을 score function 확률 쪽에서 자주 볼 수 있는 개념이다. x가 증가/감소할 때 확률밀도함수가 줄어드는 비율을 알고 있다는 건, 분포가 '드문' 사건을 어떻게 다루는지 이해하는 좋은 방법이다. 이라 부르며 \(\frac{f'(x)}{f(x)}\) 혹은 \(\require{physics} \dv{log(f(x))}{x}\)로 정의한다.

score function: \(c = 0.7\)

위 패널의 곡선은 예시로 \(c=0.7\)을 둔 \(y=e^{0.7x}\), 짧은 직선들은 \(x=0,1,2\)에서의 접선이다. 아래 패널은 같은 지점에서 계산한 \(\frac{f'(x)}{f(x)}\)이며 항상 \(0.7\)이다.

exponential function은 상수 score function 값이 정해지면 함수의 모든 값이 정해진다.

score function: \(c = -0.7\)

\(f(x)=e^{-cx}\)는 같은 방식으로 보되, 방향이 반대이다. 예시로 \(c=0.7\)을 두면 위 패널의 접선은 \(x=0,1,2\)에서 모두 음의 기울기를 갖고, 아래 패널의 \(\frac{f'(x)}{f(x)}\)는 항상 \(-0.7\)이다. 따라서 \(e^{-cx}\)는 같은 비율로 감소하는 함수이다.
