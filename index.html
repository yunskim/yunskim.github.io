데이터 분석 프로젝트

거의 모든 것의 코드를 연구합니다.

이 루트 페이지는 프로젝트 목록만 간단히 보여 줍니다. 각 프로젝트는 자체 정적 사이트, 데이터 파일, 갱신 주기를 독립적으로 관리합니다. 프로젝트 소스 폴더 안에서는 site 같은 이름을 사용할 수 있지만, 공개 URL은 프로젝트 이름을 기준으로 둡니다.

프로젝트

boxoffice

Box Office는 영화진흥위원회 일별 박스오피스 데이터를 바탕으로 한국 영화의 관객 수 흐름을 살펴봅니다. 현재 상영작, 역대 관객 수 상위작, 장기 상영 기록, 영화별 검색 기능을 제공합니다.

starbucks

Starbucks는 지방행정 인허가 자료를 바탕으로 스타벅스 입점을 시간적으로 재구성합니다. H3 셀 기반 지도로 광역 지자체별 밀집 지역과 월별 변화 흐름을 살펴봅니다.

zipcodes

Zipcodes는 한국 5자리 우편번호 prefix가 광역 권역에서 더 작은 주소 구역으로 좁혀지는 과정을 지도에서 실험합니다.

apartments

Apartments는 아파트 실거래를 일 단위 이벤트로 보고, 파크리오 85㎡대 거래를 예제로 Hawkes process 방법론을 정리합니다.

mathematics

Mathematics는 수학적 아이디어, 증명, 계산 실험을 정리하기 위한 기본 작업 공간입니다.
