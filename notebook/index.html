Notebook

증명, 계산, 시각화를 위한 HTML 노트 작업 공간

이 프로젝트는 아이디어와 계산 결과를 짧은 HTML 노트로 정리하기 위한 출발점이다. 데이터와 생성 스크립트는 프로젝트 내부의 data, scripts 디렉터리에 두고, 공개 결과는 site 아래에서 제공한다. 로컬 테스트 서버에서는 /notebook/ 요청이 notebook/site/로 매핑된다.

주제

  1. 증명 노트 정리, 가정, 증명 전략을 한 페이지 안에서 추적한다.
  2. 계산 실험 수치 예제와 시뮬레이션 결과를 재현 가능한 스크립트로 남긴다.
  3. 시각화 수식이나 구조가 눈에 보일 때 이해가 쉬운 내용을 웹에서 탐색한다.

노트

    작업 공간

    site
    정적 페이지, 스타일, 브라우저 스크립트
    notes
    HTML 원본 노트
    data
    원자료와 파생 데이터
    scripts
    데이터 생성과 검증 스크립트
