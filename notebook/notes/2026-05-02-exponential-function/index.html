Exponential Function

exponential function는 같은 비율로 증가하고 감소하는 함수이다.

2026-XX-XX

math statistics

그려보기

지수함수 \(f(x)=e^{cx}\)의 특별한 점은 미분해도 자기 자신의 상수배가 된다는 것이다. 즉 \(f'(x)=c e^{cx}\)이고, 어떤 지점 \(x=a\)에서의 기울기도 \(c e^{ca}\)이다. 그래서 수준 \(f(x)\)는 지점마다 달라지지만 상대 변화율 확률 쪽에서는 이런 걸 score function이라고 부른다. 어떤 규칙으로 한 지점에서 상대변화율이 변화하는지 파악하는 것은 확률분포를 이해하는데 도움이 된다. \(\frac{f'(x)}{f(x)}\)는 항상 \(c\)로 일정하다.

위 패널의 곡선은 예시로 \(c=0.7\)을 둔 \(y=e^{0.7x}\), 짧은 직선들은 \(x=0,1,2\)에서의 접선이다. 아래 패널은 같은 지점에서 계산한 \(\frac{f'(x)}{f(x)}\)이며 항상 \(0.7\)이다.

그래서 exponential function을 단 한마디로 요약하자면(=일상어로 설명하면) 같은 비율로 증가하는 함수라고 할 수 있다.

같은 비율로 감소하는

\(f(x)=e^{-cx}\)는 같은 방식으로 보되, 방향이 반대이다. 예시로 \(c=0.7\)을 두면 위 패널의 접선은 \(x=0,1,2\)에서 모두 음의 기울기를 갖고, 아래 패널의 \(\frac{f'(x)}{f(x)}\)는 항상 \(-0.7\)이다. 따라서 \(e^{-cx}\)는 같은 비율로 감소하는 함수이다.

그림으로 이해하기

\(y\) 대신 \(dx\)

\( f(x + y) = f(x) \cdot f(y) \)을 조금만 변형해보자.

x의 증가분 \(dx\)를 \(y\)자리에 넣으면 맥락없는 \( y \)를 넣은 때보다 패턴이 선명하게 보인다. \[ f(x + dx) = f(x) \cdot f(dx). \] 이게 무슨 뜻일까? 좌변 \( y \)자리에 \( dx \)가 들어간, \(x\)보다 \(dx\)만큼 증가한 지점의 함수값 \(f(x + dx)\)가 \( f(x) \)와 \( f(dx) \)의 multiplication이라는 것이 무슨 뜻인가?

일단 그려보기

무언가 패턴이 있을 것 같은데 답이 입 안에서 맴돌 뿐 입 밖으로 나오지 않는다면 일단 그림 논의를 단순화하기 위해 \(c = 1 \)로 정한다. 을 그려보자. \(x\)와 \(dx\)를 바꿔가며 패턴을 찾아보자.

\(f(dx)\)는 비율 \(dx\)을 입력을 받아 늘어난 값을 구하는 함수

충분히 작은 \(dx\)에 대해 \(f(x + dx)\)는 \(f(x) \cdot (1 + dx)\)에 근사하는 것을 발견했나?

\(f(x)\)가 10% 증가한 값을 \( f(x) \cdot (1 + 0.1) \)로 구한다. 마찬가지로 \(f(x)\)가 \(dx\)증가했다면 그 값은 \(f(x) \cdot (1 + dx) \)이다. \(f(dx) \approx (1 + dx) \)는 마치 증감율 \(dx\)을 받아 실제 증감을 계산하는 함수처럼 보인다.

이 방향으로 조금 더 사고를 확장해보자. \(f(dx + dx + dx)\)는 단계 \(x\)를 \((dx + dx)\), \(y\)를 \(dx\) 를 나눠 규칙을 적용할 수 있다. \[f((dx + dx) + dx) = f(dx + dx) \cdot f(dx) = f(dx) \cdot f(dx) \cdot f(dx) \approx f(dx)^3. \] 요약하자면 입력의 sum은 출력의 product로 표현된다.

한 번 더 일반화해 \(x\)가 \(dx\)가 \(n\) 개여 더해진 결과라고 보면:
\[f(dx + dx + dx + \ldots) = f(dx) \cdot f(dx) \cdot f(dx) \cdot \ldots \approx (1 + dx) ^ n = \left(1 + \frac{x}{n}\right)^n. \] 이 표현을 합과 곱 기호로 적으면:
\[f\left(\sum_{i=1}^{n} dx\right) = \prod_{i=1}^{n} f(dx) \approx (1 + dx)^{n} = \left(1 + \frac{x}{n}\right)^n.\] 여기서 \(x = n \cdot dx \)이다.
\(\sum\)은 addition을 n번 반복, \(\prod\)은 multiplication을 n번 반복하는 표기.

\(x\)를 마치 아주 작은 비율 \(dx\)의 합처럼 볼 수 있고 함수값 \(f(x)\)는 비율 \(dx\)를 모두 적용한 값으로 해석이 가능하다. 입력은 비율들의 addition, 출력은 비율이 적용된 multiplication로 이해할 수 있다. \(f(x + y) = f(x) \cdot f(y) \)라는 최소한의 가정에서 시작해 함수의 특성 파악까지 생각을 확장한 결과이다.

derivative

엄밀한 정의도 동일한 결론을 도출한다.

\(f(dt) \approx (1 + dx)\)을 가정한 것이 마음에 들지 않는다면 이번에는 formal하게 derivative를 구해보자. 정의대로 쓰면:
\[ \begin{align} f'(x) &= \displaystyle \lim_{ h \to 0 } \frac{f(x + h) - f(x)}{h} \\\\ &= \lim_{ h \to 0 } \frac{f(x)f(h) - f(x)}{h} \\\\ &= \lim_{ h \to 0 } f(x) \cdot \frac{f(h) - 1}{h} \\\\ &= f(x) \cdot \lim_{ h \to 0 } \frac{f(h) - 1}{h}. \end{align} \]

여기까지 유도하고 중간 결과에 대해 이야기 해보자. 아직 limit process가 끝나지는 않았지만 많은 정보를 얻을 수 있다.

  • \(f'(x)\)는 \(f(x)\)값에 비례한다.
  • \(f'(x)\)는 \(x\)값에 상관없이 \(\displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h}\)라는 동일한 factor에 비례한다.

\(f(x + y) = f(x) \cdot f(y) \)일 때 \(x\), \(y\)에 둘 다 \(0\)를 넣어보자. \[\begin{align} f(0) &= f(0 + 0) \\\\ &= f(0) \cdot f(0) \\\\ &= f(0)^2. \end{align}\] \(f(0) = f(0)^2\)라면 \(f(0) = 0\)이거나 \(f(0) = 1\)이다.

\(f(0) = 0\)이라면 \(f(x) = f(0 + x) = f(0) \cdot f(x) = 0 \)이라는 결과가 나와 모든 \(f(x)\)가 \(0\)이 되니 큰 쓸모가 없어진다. \(f(x + y) = f(x) \cdot f(y)\)조건은 충족하지만 바람직한 답은 아니다.

따라서 남은 \(f(0) = 1 \)을 선택할 수밖에 없다. 이 값을 limit process의 남은 항 \(\displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h}\)에 대입하면:
\[\begin{align} \displaystyle \lim_{ h \to 0 } \frac{f(h) - 1}{h} &= \displaystyle \lim_{ h \to 0 } \frac{f(h) - f(0)}{h - 0} \\\\ &= f'(0). \end{align} \]

\(f'(0) = c \)

참고 derivative에 더 많은 이야기를 듣고 싶다면 Essence of Derivative를 참고하세요.
