단위 원의 회전

\(cos(x)\)

Euler formula \(e^{i\theta} = \cos\theta + i\sin\theta\)에서 켤레인 \(e^{-i\theta} = \cos\theta - i\sin\theta\)를 더하면 허수부가 사라진다.

\[ \cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2} \]

\(sin(x)\)

이번에는 \(e^{i\theta}\)에서 \(e^{-i\theta}\)를 빼면 실수부가 사라지고 허수부만 남는다. 남은 \(2i\sin\theta\)를 \(2i\)로 나누면 \(\sin\theta\)가 된다.

\[ \sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i} \]

Euler's Helix

\(\theta\)를 앞으로 보내면 \(e^{i\theta}\)는 복소평면의 단위 원 위를 돈다. 같은 값을 \((\theta, \operatorname{Re}, \operatorname{Im}) = (\theta, \cos\theta, \sin\theta)\)로 놓으면 \(\theta\) 방향으로 진행하는 나선이 된다.
